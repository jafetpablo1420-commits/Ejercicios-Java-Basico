# Ejercicios-Java-Basico
Ejercicios prácticos y proyectos de lógica de programación en Java, enfocados en estructuras de control, algoritmos de cifrado y optimización de código.
¿Qué contiene? Programas sobre ciclos (for, while y do-while), validaciones de seguridad y menús interactivos.

Temas que estoy dominando: Switch cases, Scanner para entrada de datos, operadores lógicos y condicionales.

Meta: Construir una base sólida en Java para dar el salto a Programación Orientada a Objetos.
